# The Hollow Scripture — A Escritura Oca

![The Hollow Scripture](docs/capa.jpg)

Campanha de terror e RPG para **Minecraft Java**.

> "O verdadeiro terror não é descobrir que existe algo nas profundezas. É descobrir que alguém o colocou lá para proteger você."

O Santo Sem Nome que a Ordem do Último Sino tentou manter adormecido é **Herobrine**, feito de todos os nomes que o mundo esqueceu. Jogue do Prólogo aos capítulos I–VIII, escolha entre quatro finais e continue no pós-game.

## ⬇️ Download

Baixe a versão mais recente em **[Releases](../../releases/latest)**: `hollowscripture-0.22.0-conteudo-funcional-dev.jar`.

## Requisitos

- Minecraft Java **1.20.1**
- **NeoForge 47.1.106**
- **Java 17**

## Como instalar

1. Instale o NeoForge `1.20.1-47.1.106`.
2. Coloque o `.jar` na pasta `mods` (substitua versões antigas do mod).
3. Crie um mundo de sobrevivência e jogue normalmente.

> Versão de desenvolvimento. Faça backup do seu mundo antes de atualizar.
